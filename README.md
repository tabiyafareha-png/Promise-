# JavaScript Promises Practice

This repository contains solutions to four JavaScript Promise exercises.

## Files

1. `01-bank-account-withdrawal.js` — checks whether the account has enough balance.
2. `02-online-exam-result.js` — checks whether marks are valid and whether the student passed.
3. `03-product-delivery-system.js` — simulates a delivery that takes 3 seconds.
4. `04-promise-chaining.js` — performs a sequence of calculations using `.then()`.

## How to run in VS Code

1. Open this folder in VS Code.
2. Open a JavaScript file.
3. Run it using Node.js (for example, open the VS Code terminal and type `node 01-bank-account-withdrawal.js`).
4. Change the values in each file to practise different outcomes.

## Expected results with the default values

- Bank withdrawal: `Withdrawal Successful`
- Exam result: `Pass`
- Product delivery: `Product Delivered Successfully` (after 3 seconds)
- Promise chaining: `55`
